# 合并版验证记录

验证日期：2026-10-09。交付目录由原三个本地源码目录复制构建，未修改输入项目。验证使用已有的 Python 3.11.0、PyTorch 2.3.0+cpu、PyG 2.7.0 环境，并从项目目录之外启动交付脚本。

## 已通过

- 原统一接口的参数仍为 `G, method, stop_condition, **kwargs`，原 20 个注册名称保留，只新增 `NIRM`、`AutoSND`，合计 22 个。`degree` 示例实际运行通过。
- NIRM 使用交付目录中的原始 `Model.py` 和 `checkpoints/NIRM_onepass.pkl` 实际推理；旧 PyG 权重名称严格转换，未忽略缺失或多余权重。
- NIRM 对字符串节点 ID、空图、单节点、多个孤立节点、断连图返回完整节点排列，没有重复或遗漏；统一接口还原原始节点 ID。
- AutoSND 从嵌套包加载源码、默认配置和内置 Powerlaw_500 数据。验证期间阻止导入独立顶层 `autosnd`，因此没有借用另行安装的 AutoSND 包。
- 使用模拟 LLM、进程内候选执行，完成两个不同输入网络上的 Stage I、II、III 全过程；分别检查质量和速度方案。搜索收到的是调用者的图，代理图加载被禁止，所有候选评估都使用该输入图。
- 检查生成、结构分析、策略提案次数，最终候选、记录目录与网络来源；检查原图未被修改以及记录中的模拟凭据脱敏。
- 空网络直接返回空排列，不执行付费搜索。

通过的执行入口为 `verify_integrated.py --in-process`。此检查只在测试中替换候选进程传输，实际候选执行函数、指标评估、搜索和选择逻辑仍被使用；交付算法没有切换为进程内执行。
